# Staffing Progress Dashboard (Power BI)

## Project Overview

This project focuses on building a Power BI dashboard to monitor the staffing progress for newly opened retail stores. The dashboard consists of two key visualizations:

* **Gauge Chart** – displays the percentage of the hiring target achieved.
* **Funnel Chart** – illustrates the recruitment pipeline and conversion rates from applicants to hired employees who have started work.

## Business Scenario

A recruitment agency has been contracted to staff newly opened stores for a retail company. The objective is to hire **150 sales associates within a two-month period**.

A position is considered successfully filled only when a candidate has officially started work.

## Recruitment Process

The recruitment workflow follows these stages:

1. **Resume Screening**

   * Review incoming resumes.
   * Select candidates who meet the required qualifications.

2. **Recruiter Interview**

   * Conduct an online interview (Zoom) with qualified candidates.

3. **Manager Interview**

   * Candidates who pass the recruiter interview proceed to an interview with the hiring manager.

4. **Job Offer**

   * A job offer is extended to candidates approved by the manager.

5. **Employee Start Date**

   * The vacancy is considered closed only after the candidate accepts the offer and officially starts working.

## Dashboard Requirements

### 1. Gauge Chart

Create a gauge chart that shows:

* Hiring target: **150 employees**
* Current number of employees who have started work


### 2. Funnel Chart

Create a funnel chart representing the recruitment pipeline:

* Resumes received
* Qualified candidates after screening
* Recruiter interviews completed
* Manager interviews completed
* Job offers issued
* Employees who started work

The funnel should allow analysis of conversion rates between each stage of the recruitment process.

## Expected Outcome

The final dashboard should provide a clear view of:

* Progress toward the hiring goal.
* Recruitment efficiency at each stage.
* Candidate conversion throughout the hiring funnel.
* Overall staffing status for the new stores.
